nese Academy of Sciences. The topic of this course is commutative algebra. As most of
the students had already followed the courses Algebra I and II, where basic algebra and
homological algebra were discussed, I can concentrate on commutative algebra itself, with
the help of notions and tools from previous courses.

1.1     Prime ideals
The notions of rings, ideals, modules, and homomorphisms have been introduced in Algebra
I & II. Here are some examples of rings.
Examples 1.1.1.    1. The ring of integers Z, the quotient ring Z/nZ n ∈ Z, the field of
    rational numbers Q.

  2. Let A be a ring, for any integer n ≥ 1, we have

            A[X1 , · · · , Xn ] = {Polynomials in variables X1 , . . . , Xn with coefficients in A}

      and

      A[[X1 , · · · , Xn ]] = {Formal power series in variables X1 , . . . , Xn with coefficients in A}.

   Let us recall the definition of prime ideals.
Definition 1.1.2. Let A be a ring.
  1. An ideal p ( A is prime if ∀ x, y ∈ A such that xy ∈ p, then x ∈ p or y ∈ p.
     Equivalently, p ( A is prime if A/p 6= 0 is an integral domain.

  2. An ideal m ( A is maximal if there exists no ideal a such that m ( a ( A. Equiva-
     lently, m ( A is maximal if A/m 6= 0 is a field.
    Thus maximal ideals are prime, but not conversely in general. Also, the zero ideal (0)
(simply denoted by 0) is prime if and only if A is an integral domain.
Example 1.1.3. Let p be a prime number. Then (p) ⊂ Z is a maximal ideal. All prime
ideals of Z are of the form 0 or (p), p prime.
Lemma 1.1.4. Any ring A 6= 0 has at least one maximal ideal.
Proof. Apply the Zorn Lemma to (Σ, ⊂), where Σ = {ideals ( A}, ⊂: inclusion.

Corollary 1.1.5. Let a ( A be an ideal. Then there exists a maximal ideal of A containing
a. In particular, any non unit x ∈ A is contained in a maximal ideal.

Definition 1.1.9. Let A be a ring.

    1. The nilradical of A is

                                nilrad(A) = {nilpotent elements in A}.

       A is called reduced if nilrad(A) = 0. In general, put Ared = A/nilrad(A).

    2. Let I ⊂ A be an ideal. The radical of I is

                                r(I) = {x ∈ A | xn ∈ I for some n > 0}.

       In particular, r(0) = nilrad(A).

let f : A → A/I be the natural projection. Then we have

                                    r(I) = f −1 (nilrad(A/I)).

Thus r(I) is also an ideal. The ring Ared = A/nilrad(A) is then reduced: nilrad(Ared ) = 0.

(pq), where p is the image of p in Z/p3 q 2 Z; similarly for q.

1.2     Nakayama lemma
Before we discuss Nakayama lemma, let us briefly review some basics of module theory.
   Let A be a ring. Ideals of A are examples of A-modules (submodules of the A-module
A). Let ModA be the category of A-modules. This is an abelian category.
   For any M ∈ ModA , we have three covariant functors:

                  HomA (M, ·) :       ModA → ModA ,          N 7→ HomA (M, N ),

                        M ⊗A − :          ModA → ModA ,      N 7→ M ⊗A N,
                        − ⊗A M :          ModA → ModA ,      N 7→ N ⊗A M,
12                                                CHAPTER 1. RINGS AND MODULES

and the functors M ⊗A − and − ⊗A M are naturally isomorphic to each other; on the other
hand, we have also a contravariant functor:

                   HomA (·, M ) :   ModA → ModA ,     N 7→ HomA (N, M ).

We will often omit the subscript A in the notations HomA (M, N ) and M ⊗A N . Recall the
following basic facts:
     1. For any M, N, P ∈ ModA , there exists a canonical isomorphism Hom(M ⊗ N, P ) ≃
        Hom(M, Hom(N, P )).

     2. Let 0 → N 0 → N → N 00 be a sequence of homomorphisms of A-modules. Then
        it is exact if and only if for any M ∈ ModA , the sequence 0 → Hom(M, N 0 ) →
        Hom(M, N ) → Hom(M, N 00 ) is exact.

     3. Let M 0 → M → M 00 → 0 be a sequence of homomorphisms of A-modules. Then
        it is exact if and only if for any N ∈ ModA , the sequence 0 → Hom(M 00 , N ) →
        Hom(M, N ) → Hom(M 0 , N ) is exact.

     4. Let M 0 → M → M 00 → 0 be an exact sequence of homomorphisms of A-modules.
        Then for any N ∈ ModA , the sequence M 0 ⊗ N → M ⊗ N → M 00 ⊗ N → 0 is exact.

    Let f : A → B be a ring homomorphism. Then B can be viewed as an A-module via
f . It is then an A-algebra. For any module N ∈ ModB , we can view it as an A-module:
∀ a ∈ A, x ∈ N, ax := f (a)x. For any M ∈ ModA , the A-module B ⊗A M admits a
B-module structure: for any b, b0 ∈ B, x ∈ M, b(b0 ⊗ x) := (bb0 ) ⊗ x. In this way, we get
functors

            ModB → ModA ,       N 7→ N,   and   ModA → ModB ,       M 7→ B ⊗A M,

which are adjoint: for any M ∈ ModA , N ∈ ModB , we have natural isomorphisms

                            HomA (M, N ) ≃ HomB (B ⊗A M, N ).

    Let B, C be two A-algebras given by ring homomorphisms f : A → B, g : A → C
respectively. Then the A-module D = B ⊗A C admits a multiplication such that it is an

of rings. We have natural ring homomorphisms p1 : B → D, p2 : C → D. The triple
(D, p1 , p2 ) satisfies the universal property: for any A-algebra R and homomorphisms q1 :
B → R, q2 : C → R of A-algebras, there exists a unique homomorphism φ : D → R of
A-algebras, such that q1 = φ ◦ p1 , q2 = φ ◦ p2 . The morphism A → D is given by

                            a 7→ f (a) ⊗ 1 = 1 ⊗ g(a) = a(1 ⊗ 1).

5.1    Chain conditions
Let (Σ, ≤) be a partially ordered set. One checks easily TFAE:

  1. Every increasing sequence x1 ≤ x2 ≤ · · · in Σ is stationary.

  2. Every non-empty subset of Σ has a maximal element.

Let A be a ring, M ∈ ModA , and Σ = {submodules of M }. For the partially ordered set

descending chain condition (d.c.c. for short) and the above 2 the minimal condition.

5.2    Noetherian rings
Definition 5.2.1. A ring A is called Noetherian (resp. Artinian) if it is so as an A-module,
i.e. if it satisfies a.c.c. (resp. d.c.c.) for ideals.

    By Proposition 5.1.3, A is Noetherian ⇔ every ideal of A is finitely genereated. In
this case, one checks easily that for any ideal a ⊂ A, there exists an integer n such that
r(a)n ⊂ a. In particular, the nil radical nilrad(A) is nilpotent.

Examples 5.2.2.     1. Any field is both Noetherian and Artinian. For any integer n ≥ 1,
    the quotient ring Z/nZ is both Noetherian and Artinian. (Later we will see that in
    fact any Artinian ring is also Noetherian.)

  2. The rings Z, k[X] are Noetherian but not Artinian.

  3. A subring of a Noetherian ring need not be Noetherian: consider the integral domain
     k[X1 , X2 , · · · ], the polynomial ring with variables X1 , X2 , · · · over a field k. It is not
     Noetherian, but its fraction field is.

     4. In classical algebraic geometry, almost all the rings invovled are Noetherian rings (en-

        rian rings which are extremely important in number theory and algebraic geometry.
        These are the perfectoid rings (other than fields) introduced by Scholze in [15] (see
        also [6]).

Corollary 10.5.10. If A is a regular local ring, then so is Ap , for any p ∈ Spec A.

Proof. For any M ∈ ModAp , consider it as an A-module, then there exists a finite length
projective resolution
                           0 → Pn → · · · → P0 = M → 0,
since gl. dim A < +∞ by Theorem 10.5.9. We have then

                                         n ≤ gl. dim A.

Apply the functor − ⊗A Ap , we get an exact sequence

                         0 → (Pn )p → · · · → (P0 )p → Mp = M → 0.

This is a projective resolution of M in ModAp of length n. Since M is arbitrary, we get

                               gl. dim Ap ≤ gl. dim A < +∞,

which implies Ap is regular by Theorem 10.5.9.


   Thanks to Corollary 10.5.10, we can now define general regular rings.

Definition 10.5.11. Let A be a Noetherian ring. A is called regular if Ap is a regular ring
for any p ∈ Spec A (⇔ Am is regular for any maximal ideal m ⊂ A).

   Thus, we have the following inclusions of some basic classes of rings:

   • Regular rings ⊂ Cohen-Macaulay rings ⊂ Noetherian rings.

   • Regular rings ⊂ Noetherian normal rings ⊂ Normal rings.

The reader is encouraged to find further relations among the above rings.

   So far, we have mainly focused on the theory of Noetherian rings. To conclude, let us
mention the following recent breakthrough in commutative algebra:

Theorem 10.5.12 (André, Bhatt). Let R be a regular ring, R ⊂ S ring extensions such
that S is finitely generated as a R-module. Consider the exact sequence of R-modules

                                     0 → R → S → S/R → 0.

Then this exact sequence is split.

    The above theorem was called the “direct summand conjecture”, which is equivalent to
other versions of several deep conjectures, namely the homological conjectures on Noethe-
rian local rings in classical commutative algebra. The proofs given by André and Bhatt
(respectively) use crucially the theory of perfectoid rings [15, 6], which are very interesting
non Noetherian rings! For an overview, see André’s ICM 2018 report [1].
