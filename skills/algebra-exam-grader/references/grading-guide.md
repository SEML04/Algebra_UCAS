# 批改指南

## 一、检查层次

1. 结论层：最终答案是否与标准解答一致（注意等价表述）。
2. 论证层：每一步推理是否有效、是否由上一步推出。
3. 条件层：每个定理的所有前提是否被逐一验证。
4. 覆盖层：是否处理了全部情形与边界情形。
5. 表达层：符号、指标、作用方向、包含关系是否写反。

## 二、隐藏逻辑漏洞常见类型

- 循环论证：用要证的结论证明中间步骤。
- 未证先用：引用“显然”“由定义”但实际不显然。
- 条件误用：定理前提不满足仍套用（如不有限、不 Noether、特征整除群阶）。
- 偷换对象：混淆模与环、群与商群、扩张与分裂扩张、左模与右模。
- 反向推断：由 A⇒B 推出 B⇒A；由单射/满射直接推出同构。
- 只证充分性/必要性之一。
- 漏边界情形：零环、零模、p=2、特征 2、平凡子群、单位元、空和、非主理想等。
- 计算错误：次数/维数/阶数/指标计算、符号、指标集、作用方向。

## 三、各专题定理条件核对清单

- Galois 理论：分裂域 = 正规 + 可分扩张；特征 0 自动可分；有限可分扩张有原元；Galois 群作用在根集上；中间域与子群对应要求扩张为 Galois。
- 模论：Jordan–Hölder 需要合成列存在（有限长模）；Krull–Schmidt 需要有限长/有限分解条件；完全可约 = 半单 = 由单模生成；Artinian 与 Noetherian 互不蕴含。
- 环与代数：半单环 = Artinian 且 Jacobson 根为零；单环不必是除环；中心单代数维数与中心扩张维数平方关系；Brauer 群元素为有限维中心单代数的等价类。
- 有限群表示：Maschke 需 char(K) 不整除 |G|；特征标正交关系需完备性（正则表示分解）；Frobenius 互反需有限群与有限维表示；Brauer 定理的素数幂子群条件必须逐一核对。
- 同调代数：短正合列分裂需左右逆或投射/内射对象；长正合列中连接同态的像/核要核对；Ext/Tor 计算须固定函子方向；Koszul 复形正合要求元素构成正则序列。
